# Glenn's Math Battle

A one-file math speed game made with HTML, CSS, and JavaScript.

## Features

- Animated loading screen
- Moving background and glowing game panels
- Character selection: Guardian, Assassin, and Mage
- Easy, Normal, and Hard difficulty
- 30, 45, or 60 second game time
- Addition, subtraction, multiplication, and division options
- Type your answer or use quick answer choices
- Score, streak, energy, combo, and accuracy meters
- Best score, good score, needs practice rating
- Score history saved with localStorage
- Mobile-friendly layout
- Reduced-motion support for better performance and accessibility

## How to Play

1. Open `index.html`.
2. Choose your character.
3. Open Settings if you want to change difficulty, time, or question types.
4. Click Start Game.
5. Answer as fast as you can before the timer ends.
