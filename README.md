# Glenn's Math Battle

A browser math speed game made with HTML, CSS, and JavaScript.

## Features
- Character selection
- Easy, Normal, and Hard difficulty
- 30, 45, or 60 second timer
- Addition, subtraction, multiplication, and division choices
- Score, streak, accuracy, combo, and energy meters
- Best score, good score, and needs practice rating
- Saves scores using localStorage

## How to run
Open `index.html` in your browser.

## How to upload to GitHub Pages
1. Upload `index.html` to your GitHub repository.
2. Go to Settings > Pages.
3. Choose Deploy from a branch.
4. Select main and /root.
5. Save and open the published link.
